# COR-HARP Data Sources & Provenance

This document tracks every dataset used by the COR-HARP platform, including source, license, last-updated date, and schema notes.

---

## Primary Datasets

### 1. Nigeria HRP Political Violence Events & Fatalities
- **File:** `nigeria_hrp_political_violence_events_and_fatalities_by_month-year_as-of-13aug2026.xlsx`
- **Source:** UN OCHA / ReliefWeb — Nigeria Humanitarian Response Plan
- **URL:** https://data.humdata.org/dataset/nigeria-hrp-political-violence-events-and-fatalities
- **License:** Creative Commons Attribution for Intergovernmental Organizations (CC BY-IGO)
- **Last Updated:** 13 August 2026
- **Schema:** Columns: Admin2 (LGA), Month, Year, Events, Fatalities
- **Usage:** Primary conflict signal for LSTM training — monthly event and fatality counts per LGA

### 2. WFP Food Prices — Nigeria
- **File:** `wfp_food_prices_nga.csv`
- **Source:** World Food Programme — VAM Food Prices Database
- **URL:** https://data.humdata.org/dataset/wfp-food-prices-for-nigeria
- **License:** Creative Commons Attribution 4.0 (CC BY 4.0)
- **Last Updated:** Dynamic (WFP updates periodically)
- **Schema:** Columns: admin1 (State), admin2 (LGA), market, commodity, date, price
- **Usage:** Monthly average food prices for Rice, Millet, Sorghum, Maize across 5 target LGAs

### 3. IPC Acute Food Insecurity — Nigeria
- **File:** `ipc_nga_area_wide.csv`
- **Source:** IPC (Integrated Food Security Phase Classification)
- **URL:** https://data.humdata.org/dataset/ipc-acute-food-insecurity-data
- **License:** IPC Analytical Framework — free for non-commercial use
- **Last Updated:** Varies by analysis cycle (typically quarterly)
- **Schema:** Columns: Level 1, Area, Date of analysis, Phase 1-5 percentages, Population analyzed
- **Usage:** Food security severity indicators (Phase 3+ percentages) as LSTM features

### 4. IOM Displacement Tracking Matrix (DTM) — Nigeria
- **File:** `hdx_dtm_nigeria_r43_master_list_idp.xlsx`
- **Source:** International Organization for Migration — DTM
- **URL:** https://data.humdata.org/dataset/iom-nigeria-displacement-tracking-matrix-dtm
- **License:** Creative Commons Attribution for Intergovernmental Organizations (CC BY-IGO)
- **Last Updated:** Round 43 (varies)
- **Schema:** Columns: State, LGA, SITE NAME, Population type, Individuals, Households, latitude, longitude
- **Usage:** IDP camp populations and coordinates for map markers and demand modeling

### 5. GRID3 Nigeria Operational Wards
- **File:** `grid3_nga_operational_wards_v3_0.gpkg` (190 MB)
- **Source:** GRID3 — Center for International Earth Science Information Network (CIESIN)
- **URL:** https://data.humdata.org/dataset/grid3-nigeria-operational-wards
- **License:** Creative Commons Attribution 4.0 (CC BY 4.0)
- **Last Updated:** v3.0
- **Schema:** GeoPackage with ward-level administrative boundaries
- **Usage:** Administrative boundary geometry for map layers (not loaded into LSTM)

## External APIs (Live Data)

### 6. HDX HAPI v2 (Humanitarian API)
- **Endpoint:** `https://hapi.humdata.org/api/v2`
- **Source:** OCHA Centre for Humanitarian Data
- **License:** Free for humanitarian use
- **Usage:** Real-time IDP affected-people data, used in `page_data_inspector`
- **Auth:** App identifier header (no API key required)

### 7. SendGrid Email API
- **Source:** Twilio SendGrid
- **Usage:** Email OTP delivery for user registration
- **Auth:** API key (stored in `.env`, never committed)

### 8. Validect Email Verification
- **Source:** RapidAPI — Validect
- **Usage:** Email address validation during registration
- **Auth:** RapidAPI key (stored in `.env`)

## Notes for Collaborators

- **Data files are NOT in Git** — they exceed GitHub's 100MB limit. Download separately and place in `data:/`.
- **Model must be retrained** if data files change. Run: `cd hairp_app && python train_lstm.py`
- **All external API calls** have graceful fallbacks (offline/mock data) if the API is unreachable.
- **Data licensing:** Datasets are licensed under Creative Commons (see individual licenses above). IPC data is CC BY-NC-SA 3.0 IGO (non-commercial use only).
