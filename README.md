# COR-HARP

**Conflict-Oriented Humanitarian AI Resource Predictor**

Open-source decision-support system for humanitarian aid workers operating in Northeast Nigeria. Provides AI-driven conflict forecasting, supply chain optimization, and geospatial intelligence across five monitored Local Government Areas in Borno State.

**Live deployment:** https://cor-harp-api.azurewebsites.net/docs
**Frontend:** https://icy-river-0d05cf50f.7.azurestaticapps.net

---

## Purpose

COR-HARP was built to address a specific operational problem: aid workers in Borno State lack integrated tools for real-time conflict prediction, logistics routing, and population monitoring. The system consolidates displacement data, food security indicators, conflict event histories, and supply chain constraints into a single operational dashboard.

The platform tracks 1.36 million internally displaced persons across five LGAs (Maiduguri, Bama, Monguno, Ngala, Konduga) and provides 6-12 month conflict event forecasts generated by a 941,441-parameter LSTM model trained on historical humanitarian data.

---

## Capabilities

| Function | Description |
|----------|-------------|
| Conflict Forecasting | LSTM v2.3 model (3-layer, 192 hidden units, multi-head attention) predicting monthly conflict events per LGA |
| Supply Chain Optimization | MILP solver with Monte Carlo simulation for humanitarian convoy routing and resource allocation |
| Geospatial Intelligence | Interactive map with real-time markers, risk corridors, and LGA-level population data |
| KPI Dashboard | Live monitoring of IDP populations, food security phases, and operational metrics |
| Authentication | OTP email verification, role-based access control, and audit logging |
| Scenario Planning | Multi-agent AI copilot for humanitarian response strategy modeling |

## Model Architecture

The forecasting engine (LSTM v2.3) is a 941,441-parameter PyTorch model with the following specifications:

- **Architecture:** 3-layer LSTM with multi-head self-attention and residual FC head
- **Hidden size:** 192
- **Input features:** 23 (conflict events, fatalities, food prices for 4 commodities, IDP camp populations, IPC Phase 3+ percentages)
- **Training:** 100 epochs, Adam optimizer, temporal train/val/test split
- **Output:** Monthly conflict event predictions per LGA, 6-12 month forecast horizon

Model weights are stored in `hairp_app/models/` and served by the FastAPI backend at inference time.

## Setup

```bash
git clone https://github.com/gonisulaimann/COR-HAIRP.git
cd COR-HAIRP
chmod +x setup.sh
./setup.sh
```

For manual setup:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cd frontend && npm install && cd ..
uvicorn backend.main:app --reload --port 8000
```

The backend runs at `http://localhost:8000`. API documentation is available at `http://localhost:8000/docs`.
